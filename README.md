# -and-ST-
「and ST」の購買転換率（CVR）の改善とOMO体験の最大化に向けた解決策

## 📌 プロジェクト概要（エグゼクティブ・サマリー）

本リポジトリは、株式会社アンドエスティHD（旧：アダストリア）が運営する公式Webストア「and ST」の国内EC成長鈍化に対し、**公開決算データの統計的検証（単回帰分析）**と**UI/UX実査・フレームワーク分析（PEST / 5Forces / SWOT / Kanoモデル）**を通じて真因を特定し、具体的なWebサイト改修施策と中長期リソース配分を提案したビジネスケーススタディです。

> [!IMPORTANT]
> **コア結論：** 成長鈍化の真因は「商品力や需要の不足」ではなく、**「自社サイト固有のUI/UX課題（欠品フォロー不足・サイズ不安・ブランド縦割り構造・シニア対応の欠如）」**にあります。店舗資産（1,400店舗・スタッフ4,000名）とWebをリアルタイム連携させることで、高粗利な自社ECへの顧客回帰とCVR改善を実現します。

## 📊 1. 問題確認と過去5年間の定量的損失

直近5年間（2022～2026年2月期）において、国内EC売上高は **574億円 → 763億円** へ拡大した一方、前年比成長率は **13.7％ → 4.8％**（27/2期上期は **4.2％**）へと有意に鈍化しています（単回帰分析による年平均傾き **-2.12pt/年**、R² = 0.8758, p = 0.0194 < 0.05）。

| 損失カテゴリー | 定量的インパクト | 算出根拠・背景 |
| :--- | :--- | :--- |
| **売上増加機会の逸失** | **累計 約87億円**<br>*(年平均 約17.4億円)* | 2022年2月期のピーク純増額（+69億円）を基準とした過去5年間の増収ギャップ合計 |
| **外部モールへの利益流出** | **累計 約8.0〜12.0億円**<br>*(年平均 約1.6〜2.4億円)* | 自社EC比率の低下（-0.3pt＝年約8億円分流）に対し、一般的モール手数料率（20〜30％）を乗じて推計 |
| **休眠会員の滞留** | **1,460万人（休眠率 64.3％）** | 総会員2,270万人のうち、直近1年間のアクティブ会員は810万人にとどまり、自社ブランド成長率も **+4.0％**（実質約+1％）に低迷 |

## 🔍 2. 成長鈍化の真因特定

国内全体のEC化率が **28.8％（+0.4pt）** へ上昇する中、**自社EC比率のみ 14.6％（-0.3pt）** へ逆行低下（ZOZOTOWN等の外部モール比率は **14.2％ / +0.7pt** へ上昇）しており、消費者が同じ自社ブランドを外部モールで購買している実態が明らかになりました。

決算分解・業界離脱データ・経営方針・現行サイトUI実査のクロス検証により、以下の**4つの構造的ボトルネック**を特定しました：

1. **EC欠品時の店舗在庫未連携**：EC倉庫の在庫切れ時に購入ボタンが即座に無効化（「在庫なし」）され、全国約 **1,400店舗** の現物在庫へシームレスに誘導できていない。
2. **同体型スタッフ着画の視認性不足**：約 **4,000名のスタッフ（Staff Board）** の着用画像がページ下部に折りたたまれており、インフレ下で返品コストに敏感なユーザーの「サイズ不安」を払拭できていない。
3. **「ブランド縦割りUI」による回遊性の低さ**：ブランドロゴ別の館構成に偏っており、外部出店 **82店舗**（GMV成長率 +77.7％〜301.6％）やコスメ・雑貨とのシーン別横断提案が弱い。
4. **シニア配慮および動的レコメンドの欠如**：文字サイズ・決済導線の煩雑さが **50〜69歳シニア層（スマホ普及率 89.4％）** の離脱を招き、また固定的な季節陳列が「暖秋（平年比 +1.97℃）」等の気温変動に即応できていない。

## 📈 4. 効果検証設計と2030年中期経営計画への貢献

* **統計的検証（A/Bテスト）**：全面展開前に新UI（実験群）と現行UI（対照群）へ **50％：50％のランダムトラフィック配分** で2週間並行稼働させ、CVRおよびAOVに対して独立2標本t検定（有意水準 **p < 0.05**）を実施して因果効果を実証します。
* **短期・中長期ノーススター指標**：
  * **短期（3ヶ月後）**：自社EC全体のCVR **+0.6pt〜+1.0pt改善**、自社EC比率の低下トレンド反転。
  * **2030年リソース配分（100％）**：**①オープンプラットフォーム拡大（50％投入：GMV 1,000億円・外販比率40％）**、**②2,270万会員のカテゴリー横断リピート深化（35％投入：購買頻度 3.0回 → 4.5回）**、**③アジア越境EC＆シニアUI最適化（15％投入）**。
